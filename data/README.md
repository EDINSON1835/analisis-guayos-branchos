# Datos

Aquí va `dataset_guayos_selenium.csv`, el archivo que exporta el cuaderno de Colab (o `scripts/run_scraper.py`).
El flujo de despliegue lo usa para construir el informe web.

Columnas: `sku, nombre, marca, precio_lista, precio_final, descuento_pct, disponible, url`.

Los precios cambian con las campañas de la tienda: el archivo describe el momento de la extracción.
